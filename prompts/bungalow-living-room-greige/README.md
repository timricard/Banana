# Bungalow living room, greige sofa scheme

This is a second version of `../bungalow-living-room/`. The room, the views and the lighting are the same.
The blue-velvet version is still in its own folder.

| File | Use |
|------|-----|
| `spec.json` | Main spec: shared room, furniture and lighting, plus all three views |
| `view-a-fireplace.json` / `view-b-south.json` / `view-c-north.json` | One file per view, ready to paste |

The steps for keeping the views consistent are the same as in `../bungalow-living-room/README.md`.
Render View A first, then attach it as a reference image when you render B and C.

## What differs from the blue scheme

- **Sofa:** the existing warm greige sofa, about 90 in wide, with track arms, loose back cushions and tapered walnut legs.
- **Lounge chairs:** one rust and one deep forest green. Rust is **south** of the fireplace and green is **north**. The green
  chair is near the library end, and the rust chair is near the walnut stool and bar.
- **Other colors:** rust boucle ottoman, olive linen reading chair, dark olive glazed lamps, rust throw, and an indigo
  velvet pillow in place of the oatmeal one.
- **Art:** the east-wall abstract has more indigo, so it reads as the darkest, richest object on that wall. The mantel vessel is now dark.
- **Negative prompt:** your full list, plus "CGI sheen" and "furniture that changes between views".

## Fixes carried over from the first version

- **View A camera:** the camera sits at the east wall on the sofa's centerline, with the lens above the sofa back. The sofa is against the wall, so nobody can stand behind it.
- **Ficus:** about 8 ft overall so it clears the 9 ft ceiling.
- **Rug:** 14 ft runs north–south so it fits inside the walnut border.
- **Throw:** on the north arm of the sofa.
