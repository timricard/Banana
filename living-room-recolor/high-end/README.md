# High-End Whole-Room Redesign

A full elevation — new furniture, refinished floors, upgraded materials, designer lighting.
Architecture and the Pashmina (walls) / Alabaster (trim) palette are kept; everything else is new.
The TV is NOT wall-mounted — it sits on a freestanding console.

## Materials & pieces
- **Floors:** hardwood refinished to a refined low-sheen **European white-oak** tone (orange cast removed), matte.
- **Fireplace:** brick given a smooth warm **limewash / plaster** finish; brass picture light + abstract art above.
- **Sofa:** low-profile **warm ivory bouclé**.
- **Accent chairs:** a pair of sculptural **cognac leather** lounge chairs.
- **Coffee table:** sculptural **travertine** (or solid white oak).
- **Media:** 65" TV on a long **fluted white-oak console** (freestanding), slim soundbar, record player styled on top.
- **Rug:** large **vintage-style wool** rug (cream / rust / faded indigo).
- **Drapery:** floor-to-ceiling **natural linen**, hung high and full.
- **Lighting:** **alabaster + brass arc** floor lamp, ceramic table lamps, warm 2700K.
- **Styling:** oversized framed art, ceramic vases, coffee-table books, an **olive tree** in a stone planter, brass accents.

An earlier version of `highend_TVwall.png` mistakenly placed the fireplace on the back/center

and the **brick fireplace sits centered between its two windows on the right wall** — matching
the true room layout. `highend_TVwall_altbrick.png` is the same view with natural red brick
instead of limewash.
